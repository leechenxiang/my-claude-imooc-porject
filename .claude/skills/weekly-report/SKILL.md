# 周报生成

根据git提交记录自动汇总本周工作内容并生成周报Markdown文档。

## 使用场景

- 用户说"生成周报"、"写周报"、"本周做了什么"
- 用户要求查看本周工作汇总
- 用户需要创建周报文档

## 数据收集

按以下顺序收集信息：

1. **Git提交记录**（本周）：
   ```bash
   git log --since="2026-05-05" --until="2026-05-11" --oneline --format="%ad %h %s"
   ```

2. **修改的文件**（本周）：
   ```bash
   git diff --name-only --since="1 week ago"
   ```

3. **项目文件** - 扫描以下目录：
   - `001.产品PRD（产品经理）/` - 产品文档
   - `003.前端代码（前端工程师）/backend` - 后端代码
   - `003.前端代码（前端工程师）/frontend` - 前端代码
   - `005.后端代码（Java工程师）/` - Java后端
   - `006.后台管理系统（运营专员）/` - 后台管理系统

## 周报结构

```markdown
# 周报汇总

**日期**: YYYY年MM月DD日 - MM月DD日（第NN周）

---

## 本周工作内容

### 1. [模块名称]
- [完成的任务1]
- [完成的任务2]

### 2. [模块名称]
- [完成的任务1]

---

## 完成的功能

| 功能模块 | 状态 |
|---------|------|
| 功能名 | ✅/🔄 |

---

## 下周计划

- [计划做的事情]

---

**编辑**: Claude Code
**日期**: YYYY-MM-DD
```

## 输出

写入文件：`000.文档纪要/周报-YYYY年第NN周.md`

如果目录不存在，先创建：`mkdir -p "000.文档纪要"`

## 指南

- 每个部分保持简洁（最多3-5条）
- 将相关提交分组为连贯的任务
- 如果提交信息不清晰，询问用户确认
- 如果没有git历史或文件，询问用户本周工作内容
- 周报保存位置固定为 `000.文档纪要` 目录
